# Quaternius civilian characters

Original models and animations: Quaternius, CC0 1.0.

Author pages: https://quaternius.com/packs/ultimatemodularcharacters.html and https://quaternius.com/packs/ultimatemodularwomen.html. Both author pages explicitly list CC0 and commercial use. The author website source was verified through Quaternius/quaternius.github.io.

Converted GLB redistribution: Luan Michel Ducate, Ducz.CharacterCreator, pinned commit fcd215b58eec5c9ed97d0ba5f696d0e7dc085e08. Its README explicitly identifies these models and animations as Quaternius CC0 assets. The original LICENSE-Quaternius.txt is retained alongside this notice. Only model files were imported, not the character creator application code.

Each model's immutable source URL, source/processed SHA-256 and size are recorded in manifest.json. Kafe Miaw retains five useful clips and losslessly repacks their referenced buffers; geometry, materials, skeleton and retained animation samples are preserved. Kafe Miaw supplies runtime tinting, seated/carrying bone poses and application code.
